🔒 Kebijakan Privasi

Berlaku efektif: 1 Januari 2026 · Versi 2.6.0

✅ RINGKASAN: Aplikasi ini memproses video 100% lokal di browser Anda. Kami TIDAK mengumpulkan, menyimpan, atau mengirim video Anda ke server manapun. Tidak ada akun, tidak ada tracking, tidak ada iklan.

1. Prinsip Dasar

AI Agent dirancang dengan filosofi "Privacy by Design":

  • ✅ Semua pemrosesan video terjadi di perangkat Anda
  • ✅ Tidak ada upload ke server
  • ✅ Tidak ada akun pengguna
  • ✅ Tidak ada cookie tracking
  • ✅ Tidak ada analytics pihak ketiga
  • ✅ Tidak ada iklan

2. Data yang Kami TIDAK Kumpulkan

Kami tidak pernah mengumpulkan:

  • ❌ Video atau audio yang Anda proses
  • ❌ Nama, email, nomor telepon, atau identitas apapun
  • ❌ Lokasi geografis
  • ❌ Riwayat browsing
  • ❌ Kontak atau file pribadi
  • ❌ Data biometrik

3. Data yang Disimpan LOKAL di Perangkat Anda

Aplikasi menyimpan data berikut di localStorage & IndexedDB browser Anda — data ini tidak pernah keluar dari perangkat:

Data Tujuan Hapus Otomatis?
Workspace (klip hasil) Auto-save agar tidak hilang saat refresh Manual (tombol Mulai Baru)
Preferensi tema Dark/Light mode Tidak
LLM cache Percepat generate copy berikutnya Ya (30 hari / 500 entry)
Behavior log Auto-downgrade jika crash berulang Ya (max 30 run)
Benchmark result Setting device optimal Manual (Reset Settings)
Feature flags Status toggle fitur Tidak

Cara hapus semua data lokal: Buka DevTools → Application → Clear Storage, atau uninstall PWA.

4. Koneksi ke Pihak Ketiga

⚠️ PERHATIAN: Meskipun video Anda tidak di-upload, Aplikasi mengunduh resource dari internet saat pertama kali digunakan:
Layanan Yang Diunduh Tujuan
jsDelivr / unpkg Library JavaScript (MediaPipe, transformers.js) Runtime AI
storage.googleapis.com Model MediaPipe (face, pose, gesture) Deteksi visual
huggingface.co Model LaMini-Flan-T5 (jika LLM diaktifkan) Generate copy AI
Google (jika speech) Audio mic (fitur eksperimental) Transkripsi suara

Catatan: Setelah resource ini tersimpan di cache browser (Service Worker), Aplikasi dapat berjalan 100% offline.

5. Fitur Speech Recognition (Eksperimental)

⚠️ PERHATIAN KHUSUS: Jika Anda mengaktifkan fitur "Rekam Suara" untuk transkripsi, fitur ini menggunakan Web Speech API bawaan browser. Artinya:
  • 🎙️ Mikrofon Anda akan aktif
  • 📡 Audio dikirim ke server Google (browser-dependent)
  • 🔓 Kami tidak bisa mengontrol bagaimana Google memprosesnya
  • ⚠️ Fitur ini OPSIONAL dan harus diaktifkan manual
  • 💡 Kami menyarankan gunakan mode "Manual" / "Tempel Teks" saja

Dengan mengaktifkan fitur ini, Anda menyetujui pemrosesan audio oleh Google sesuai Kebijakan Privasi Google.

6. Anak di Bawah Umur

Aplikasi ini tidak ditujukan untuk anak di bawah 13 tahun (atau 16 tahun di Uni Eropa). Kami tidak dengan sengaja mengumpulkan data anak-anak.

7. Keamanan

Karena semua pemrosesan bersifat lokal:

  • ✅ Tidak ada risiko kebocoran server
  • ✅ Tidak ada penyadapan (kecuali fitur speech)
  • ✅ Data Anda hanya sekuat keamanan perangkat Anda

Tips: Gunakan perangkat dengan kunci layar aktif, dan hindari memproses video sensitif di perangkat publik.

8. Hak Anda (GDPR/CCPA-style)

Meskipun kami tidak menyimpan data Anda, Anda tetap berhak untuk:

  • Akses — semua data ada di browser Anda (DevTools → Application)
  • Hapus — clear browser storage kapan saja
  • Portabilitas — export data via fitur Backup di Settings
  • Keberatan — berhenti menggunakan Aplikasi

9. Perubahan Kebijakan

Kebijakan ini bisa diperbarui. Perubahan besar akan diumumkan di halaman utama Aplikasi. Tanggal berlaku akan diperbarui otomatis.
